# 上线测试表格

**测试前提：** 使用测试环境与测试账号；不使用生产简历、生产 Cookie 或真实招聘账号；投递仅走沙箱页，不向 BOSS 等真实平台外发。准备两个互不关联的人才账号、PDF/Word/异常简历文件、通用岗位与三类 JD（正常、无效、超长）、可授权及拒绝摄像头/麦克风的测试场景。

**记录要求：** 每次测试请同步记录测试人、版本、截图或请求号。最后一列留给你填写测试结果。

| 序号 | 测试模块 | 检查项 | 预期结果 | 测试结果 |
| --- | --- | --- | --- | --- |
| 1 | 进来和账号 | 注册/登录后进入人才页而非运营后台；首屏为求职建议空页且左侧有历史会话；四个入口（求职建议、简历诊断、智能投递、模拟面试）可点击；个人档案、身份与安全、账号、本机助手不串页；退出再登录；按本轮开通情况验证手机号和第三方登录；检查邀请码入口和旧链接。 | 登录后页面正确、会话保留且身份不变；各入口和设置页独立；已开通的登录方式可用，未开通项如实记录；邀请码不作为新入口，旧链接仅受控兼容。 |  |
| 2 | 求职建议 | 查看空页、新建会话、查看历史；发送一句日常求职问题；刷新、前进、后退；检查是否触发自动上传简历、核验、投递或面试；检查新建议开关。 | 可正常回复；失败时有清晰提示而非持续转圈；会话与当前入口不丢失；不自动触发其他业务；“带市场来源的新建议”保持关闭且不作为本轮验收项。 |  |
| 3 | 简历诊断 | 上传 PDF、Word；上传空文件、超大文件和异常格式；选择通用岗位、正常 JD、无效 JD、超长 JD；查看报告、证据与分类；编辑、保存、重新核验；查看历史报告和旧链接；完成后观察是否自动跳转；账号 B 尝试访问账号 A 报告。 | PDF/Word 可生成核验报告；异常文件被拒绝并说明原因；异常 JD 不使系统崩溃；证据可对应原文；缺口、没把握、矛盾、系统失败可区分，服务故障不误判为用户能力问题；报告可编辑复核且历史可访问；不自动投递/开面试；账号隔离有效。 |  |
| 4 | 智能投递（沙箱，不外发） | 查看当前投递工作台和只读目录；无核验简历时尝试确认发送；有简历时检查可选岗位；验证“投/不投”、批量确认、招呼语、二次确认及原因留痕；按“确认→一次性票→沙箱动作”测试本机助手；测试票过期、票复用、修改岗位/招呼语、验证码、掉登录、页面跑偏、停止、总闸、账号 B 使用 A 凭据；点击自动群发/新浏览器助手/多渠道代投。 | 不出现旧四页签；只能操作本人核验岗位；仅勾选项被确认；招呼语不编造经历；“不投”有二次确认与记录；无票或票失效/复用/内容变更均不能动作；异常立即停止，用户停止优先，总闸阻止新发送；确认凭据隔离；关闭能力不可执行；全程不真实外发。 |  |
| 5 | 模拟面试 | 从当前入口开一场并进入既有房间；检查题目来源、技能、难度、题型；检查选择题页面与接口；作答后断网重连；拒绝摄像头；模拟视频失败；完成并查看报告；检查是否触发改简历或投递；账号 B 尝试访问 A 的房间/报告；检查准备计划和新报告投影开关。 | 题目可追溯；选择题不泄露答案；断网后已答内容保留且不换题；拒绝摄像头仍可文字/语音继续；视频未评有明确提示；报告仅覆盖知识、表达、行业、红线、临场，不推断人格、健康或受保护身份；不产生连带动作；账号隔离有效；关闭能力不作为成功路径。 |  |
| 6 | 几个入口之间 | 在四个入口间反复切换；查看简历页、投递页、面试详情页的侧栏高亮；打开求职建议旧地址、旧投递页、旧简历报告、旧面试房间；输入无效页签。 | 当前入口与高亮一致；旧书签可迁移到正确页面，不 404、不丢失报告或场次编号；无效页签回到默认页，不出现空白页。 |  |
| 7 | 系统出问题的时候 | 分别模拟简历核验服务、投递服务、面试服务不可用或断线；在各流程中刷新网页。 | 简历服务异常提示“系统暂不可用”，不表述为核验不通过；投递不外发且不留下半条发送；面试可恢复或明确失败，不重复计分/出报告；刷新后仍在原入口和原业务。 |  |
| 8 | 浏览器和常用分辨率 | 在 Chrome、Firefox 各完成登录、简历、投递、面试主路径；以普通笔记本宽度和手机宽度检查导航、上传、表格、弹窗、加载、空数据、失败和降级状态。 | 两种浏览器主路径可用；两种宽度可完成全流程；页面无横向溢出；所有状态有清晰提示；不出现双侧栏、双设置页或双面试房间。 |  |
| 9 | 本轮不要拿来当“已上线”的能力 | 检查新求职建议（带市场来源、可保存）、简历新身份/新版本对比/批准后投递、授权自动投递/多渠道代投、插件开放接口、个人账户开放 Key。 | 仅确认这些能力的开关关闭或操作被拒绝；不产生成功结果、不写入正式业务数据；不因这些关闭项阻挡本轮发布判断。 |  |
